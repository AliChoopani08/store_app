# 🏪 Store App

A production-ready online store backend built with **Java 21**, **Spring Boot**, and **Docker**, focused on security, scalability, and clean architecture.

## 🚀 Features

### 👤 User Management

- User registration and login
- JWT Authentication & Refresh Token
- Role-Based Access Control (User/Admin)
- Profile management (view, update, delete)
- Secure endpoints with Spring Security

### 🛒 Store Management

- Product CRUD operations
- Category management
- Shopping cart functionality
- Order creation from cart data
- DTO validation
- Spring Data JPA & Hibernate integration

### ⚙️ Architecture & Quality

- Layered architecture
- Global Exception Handling
- Custom exception hierarchy
- MapStruct for DTO mapping
- Lombok for boilerplate reduction
- Comprehensive testing

### 🐳 Docker Support

- Dockerized Spring Boot application
- Docker Compose support
- Easy deployment with containerized services

## 🐳 Running with Docker

### 1. Build Jar File

```bash
mvn clean package
```

### 2. Build Image

```bash
docker build -t store-app .
```

### 3. Run with Docker Compose

```bash
docker compose up -d
```
